## Flags and behavior

- `full_codemode` defaults on in local/dev and off in release builds (`77b322ceae`). The model policy decides which tools move into Code Mode; the sync adds no flag of its own.
- `todo` briefly became config-only in `77b322ceae`; the pinned tip includes `56dc95bff5`, which restores explicit opt-in via `OPENCODE_FLAGS=todo` **or** `experimental.todo: true`. It stays off by default, even in local/dev, and neither `all` nor `all_flags` turns it on. This differs from the config-only description in the plan.
- Cold server locations no longer wait for provider plugin activation in the affected endpoints. Clients see the current state and keep their existing refresh/wait responsibilities.
- Older builds cannot decode persisted `Job.Recovery` rows with `kind: "video"`. This is a rollback compatibility caveat even though no SQL migration is added.
