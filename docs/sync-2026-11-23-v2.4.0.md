## Behavior changes to review

- **Automation tool names.** `tools.shuvcode.automation_*` / `shuvcode_automation_*` become `tools.automation.*` / `automation_*`. Permission rules that name the old tools need updating.
- **Unattended denylist.** Upstream now lets automation code call `shell`, `session.rename` and the worktree tools. The permission prompts at creation are marked `unattended`. Only automation management and `session.move` stay blocked. This follows upstream's design and its tests. Keeping the fork's stricter list instead would break upstream's `automation-shell` capability test and is a policy decision for Cap.
- **Automations default on.** They use the top-level `automations` key, and `experimental.automations` no longer applies.
