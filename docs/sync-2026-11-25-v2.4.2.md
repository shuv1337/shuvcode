## Fork preservation

- **MCP Skills.** #518 still enables SEP-2640 skills across release channels by default; `experimental.mcp_skills: false` and `OPENCODE_FLAGS=-mcp_skills` opt out. #517 still forwards `skills` through `McpPool`, returns typed `Skill.LoadError` from session skills and rejects disabled or unavailable Code Mode API requests before asking for permission. Upstream #66210 disambiguates same-named skills by their paths, #66244 adds the source server to activated instructions, and #66220 resolves an unlisted skill by a URI the server confirms. These behaviors are covered by the MCP Skills and session skill suites.
- **Claude Agent SDK.** Layer 1: `ProviderPlugins` does not load the upstream Claude Agent SDK plugin, and the CLI does not bundle its folder worker. Layer 2: `ConfigProviderPlugin` still skips both provider IDs. Layer 3: the 18 package-file `isHiddenProvider` footprint is intact, including the new integration-connect check and model-picker title lookup; `claudeAgent` i18n keys remain absent. Upstream source stays in the tree; Shuvcode's bundled Anthropic integration is still `ClaudePlugin`.
- **#429 / push.** Root-family permission routing, orphan cancellation and the child waiting banner remain. `PushWatcher` now removes cancelled child asks from its pending set and clears their parent-routed notification immediately. The focused regression requires the clear before any execution-end event. The mobile contract's `session.title || "OpenCode"` fallback remains unchanged.
- **Storage.** Upstream `2709f3a554` (#66473) makes Drizzle delegate SQLite transaction and savepoint ownership to Effect `SqlClient`; no migrations are added. Tests cover rollback, nested transactions and interruption.
- **Other fork invariants.** #513 remains in effect (no fork GPT-Live plugin); #515 (OpenAI Ultrafast), #510/#512 (Solstice), the Night Owl default and browser status/replay/grace paths remain. `Global.app`, service ports, the npm updater, fork publish guard and CLI bin are unchanged. The new `generate_image` and `generate_video` registrations follow upstream Code Mode behavior.
