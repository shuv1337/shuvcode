### Deliberate upstream exception — requires reviewer attention

Upstream #63040 (`374c97b57e`) reinstates server-side plugin activation waits and 5-second 503 responses for policy-managed provider endpoints. The supplied fork instructions explicitly prohibit these waits, including generate and websearch actions. This sync therefore excludes that commit's eight-file behavioral/documentation/test delta and preserves the existing snapshot/non-waiting contract.

**Known tradeoff:** upstream added the waits because managed policy is applied by the final plugin, so an early request can observe/use a provider before that policy removes it. This sync does not solve that existing exposure. Do not treat this divergence as a risk-free mechanical resolution; the orchestrator should review the policy decision before merging. No speculative replacement architecture was added.
