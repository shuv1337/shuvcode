These docs are for the beta version of Shuvcode, which will become Shuvcode 2.0. The beta is still changing: we may wipe
your data, things may break, and APIs, configuration, and plugin APIs may change.

Shuvcode 2 installs and runs as `shuvcode`. It does not replace Shuvcode 1's `opencode` binary, so you can keep both
versions installed and run them side by side.

## Install

<Callout type="note">The curl install script is not available in beta.</Callout>

<div data-install-code>
  <CodeBlock
    code={`$ npm install -g shuvcode@beta
$ bun install -g --trust shuvcode@beta
$ pnpm add -g --allow-build=shuvcode shuvcode@beta
$ yarn global add shuvcode@beta`}
  />
</div>

The package uses a trusted postinstall script to select the native `shuvcode` binary for your platform. The Bun and pnpm
commands above explicitly allow that script to run.

Homebrew, Arch Linux, Windows package managers, Docker, and standalone binaries are not supported during the beta.

## Connect

Shuvcode has built in support for many LLM providers - you can connect to them
directly [in the TUI](/cli/providers) with `/connect`.

See [Providers](/providers) to configure custom providers.

If you'd like easy access to all the best coding models you can try out
[Shuvcode Console](https://console.opencode.ai).

You can also try [Shuvcode Go](https://opencode.ai/go) a $10/month subscription
plan that grants you access to the best open source models.

## Customize

Make Shuvcode your own by editing the [Shuvcode config](/config), [connecting MCP servers](/mcp-servers), or [creating
commands](/commands). For terminal interface themes and keybindings, see [CLI configuration](/cli/config).
